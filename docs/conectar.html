Local Commander V8.1

Conectar este computador ao ChatGPT

Guia completo da instalação até o primeiro teste. Na maioria dos casos você só abre LocalCommander-V8.1.bat e segue os passos abaixo.

Abrir página de conexão Abrir plugin Local Commander
1

Abra o BAT

Dê dois cliques em LocalCommander-V8.1.bat. Na primeira execução ele baixa um Python portátil para runtime/python e instala as dependências somente dentro desta pasta. O Windows não recebe uma instalação global de Python. Quando terminar, a mesma janela é limpa e vira o dashboard do Local Commander.

Nas execuções seguintes o setup é pulado automaticamente. Para remover o Python portátil, basta apagar a pasta do Local Commander.

2

Pairing / pareamento

Se o computador ainda não estiver associado, o Local Commander mostra um código e abre a página de conexão. Entre com a mesma conta do ChatGPT e confirme o dispositivo.

O caminho recomendado da V8.1 é:

PC → Local Commander V8.1 → Hosted Relay → Plugin Local Commander → ChatGPT

Este fluxo não precisa expor uma porta pública do seu PC.

3

Plugin do ChatGPT

Abra o plugin Local Commander e conecte-o à sua conta. Depois volte ao chat e peça algo simples, por exemplo:

Liste a pasta Downloads deste computador.

Se houver mais de um aparelho conectado, o ChatGPT escolhe o dispositivo pelo nome.

4

Permissões

Por padrão esta build usa o perfil user: acesso somente ao perfil do usuário do Windows. Isso inclui normalmente Desktop, Downloads e Documents.

O perfil pode ser alterado depois no arquivo de configuração localizado em %APPDATA%\LocalCommanderV8\config.json. Use acesso total somente em computadores nos quais você confia.

5

Dashboard e atalhos

Ctrl+Alt+MMinimiza a janela. O agente continua ativo.
Ctrl+Alt+PPausa/retoma a execução de comandos.
Ctrl+Alt+DRedesenha o dashboard/status.
Ctrl+Alt+HAbre este guia.
Ctrl+Alt+QEncerra o Local Commander.
6

E o OpenAI tunnel-client?

Para a V8.1, o Hosted Relay é o caminho recomendado. O plugin que você já usa aponta para o relay hospedado, então o tunnel-client oficial não é obrigatório para esse fluxo.

O OpenAI tunnel-client é útil para desenvolvimento/integração MCP direta ou para uma instalação alternativa. Não ative os dois caminhos ao mesmo tempo sem necessidade, porque isso dificulta o diagnóstico.

Se no futuro você optar pela versão de túnel direto, configure o MCP local, inicie o tunnel-client e adicione a URL gerada ao ChatGPT. Essa é uma arquitetura separada da conexão hospedada desta V8.1.

Crie um arquivo chamado teste-local-commander.txt em Downloads.

Se não conectar

Plugin não aparece: abra o link do plugin acima, confirme que está na mesma conta do ChatGPT e recarregue o chat.

Dispositivo offline: mantenha o BAT aberto; confirme internet e firewall. Pressione Ctrl+Alt+D para atualizar o dashboard.

Pairing expirou: apague %APPDATA%\LocalCommanderV8\device.dpapi com o Local Commander fechado e abra o BAT novamente.

Duas instâncias: feche as janelas antigas do Local Commander antes de iniciar outra.

Browser automation não funciona: execute no terminal da pasta: .venv\Scripts\python -m playwright install chromium.

Git não funciona: instale Git for Windows. O Local Commander detecta git.exe automaticamente.

Remover deste computador

Feche com Ctrl+Alt+Q. Depois apague a pasta do Local Commander e, se quiser revogar o pareamento local, apague %APPDATA%\LocalCommanderV8. Para computadores compartilhados, remova também o dispositivo pelo painel/página de conexão.

O Local Commander pode executar comandos e editar arquivos dentro do perfil autorizado. Só mantenha conectado em computadores que você controla.

V8.1 — Tool Mode e Agent Mode

Tool Mode é o comportamento clássico: você pede uma ação e o ChatGPT chama uma ferramenta local.

Agent Mode mantém estado de uma tarefa longa no computador. O ChatGPT continua sendo o cérebro e envia os passos; o Local Commander guarda task id, progresso, checkpoints, validações e sessões persistentes.

Você → ChatGPT → plano/decisão → Local Commander V8.1 → PC → resultado → ChatGPT

A V8.1 não instala nem executa uma LLM própria e não pede uma API key local.

Nota: as novas ações da V8.1 precisam ser adicionadas ao schema do plugin Local Commander para ficarem chamáveis diretamente pelo ChatGPT. As ferramentas da V8 continuam compatíveis.
