# Nova TV v0.2 — Hisense 32A4HA Android TV 11
Visual híbrido Projectivy/Apple TV/FreeMyTVWebOS (implementação própria), com destaques, dock e linhas horizontais.
Personalização em ⚙: 4 temas, fotos de fundo, remoção de foto e emparelhamento do telemóvel.
Favoritos: manter OK pressionado; lançar apps: OK.
Comando pelo telemóvel: instalar Nova TV Remote, abrir menu ⚙ > Emparelhar telemóvel e introduzir IP e PIN.
A conexão funciona apenas enquanto este launcher está aberto e os dispositivos estão na mesma rede de confiança; protocolo TCP local sem TLS.
Não controla outras aplicações, não altera os serviços Android nem substitui o launcher original da Hisense.
Não precisa de root, AccessibilityService ou ADB.
