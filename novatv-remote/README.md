# Nova TV Remote
APK para telemóvel Android, touchpad via rede Wi-Fi local com PIN de seis dígitos.
É preciso abrir Nova TV na televisão para o cursor funcionar. Sem acesso aos outros apps nem controlo universal nesta versão.
Abra Nova TV > Definições > Emparelhar telemóvel, veja IP e código e introduza-os neste APK.
Sem contas, anúncios, cloud ou dados guardados em servidores. A ligação usa TCP local sem TLS, utilizar apenas em redes confiáveis.
